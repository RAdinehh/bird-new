## 🔤 Typography Scale

**پایه:** `--fluid-base: clamp(13px, 3.6vw, 15px)`

| توکن | نسبت | کاربرد |
|------|------|--------|
| `--fs-xs` | 0.75× | caption |
| `--fs-sm` | 0.85× | زیرعنوان |
| `--fs-base` | 1× | متن اصلی |
| `--fs-md` | 1.15× | عنوان کوچیک |
| `--fs-lg` | 1.3× | عنوان |
| `--fs-xl` | 1.5× | KPI |
| `--fs-hero` | 2.2× | Hero |

**قاعده:** فقط از این ۷ سطح. هیچ `fontSize: 14px` مستقیم.

## 📏 Spacing Scale

**پایه:** `--sp-unit: max(4px, 1vw)`

| توکن | مقدار |
|------|-------|
| `--sp-1` | ~4px |
| `--sp-2` | ~8px |
| `--sp-3` | ~12px |
| `--sp-4` | ~16px |
| `--sp-6` | ~24px |

**Padding Presets:**
- `--pad-tight`: 6px 8px
- `--pad-normal`: 8px 12px
- `--pad-comfy`: 12px
- `--pad-loose`: 16px

**Gap:**
- `--gap-xs` (4px) — بین آیکون و متن
- `--gap-sm` (8px) — بین کارت‌ها
- `--gap-md` (12px) — بین بخش‌ها

## 🇮🇷 RTL + فارسی

| جایگزین | به جای |
|---------|-------|
| `٬` (U+066C) | `,` |
| `٫` (U+066B) | `.` در اعشار |
| `—` | `:` در UI |
| `«...»` | `"..."` |

**قاعده:** هر عدد با `toFa`. جهت ltr برای اعداد لاتین.
