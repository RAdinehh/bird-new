## 🎨 بخش ۱ — چیدمان
- **دو ستونه پیش‌فرض** برای فیلدهای کوتاه (عدد، تاریخ، انتخاب)
- **تک‌ستونه** برای فیلدهای بلند (نام، آدرس، توضیحات)
- **حداکثر ۲ ستون در موبایل** (سه ستون ممنوع)
- فرم‌های بلند → افشای تدریجی (Progressive Disclosure)

## 📏 بخش ۲ — فاصله‌گذاری (مضرب ۸)
| اندازه | کاربرد |
|---|---|
| ۴px | فاصله ریز |
| ۸px | بین برچسب و فیلد |
| ۱۶px | بین فیلدها |
| ۲۴px | بین بخش‌ها |
| ۳۲px | بین کارت‌ها |
| ۴۸px | بین بخش‌های اصلی |

**ممنوع:** مقادیر دلبخواه مثل ۱۳px، ۲۷px

## 🎯 بخش ۳ — فیلدهای ورودی
- برچسب **بالای فیلد** (نه placeholder)
- **حداکثر یک متن کمکی** در هر فیلد
- خطا **زیر فیلد** (Inline Error)
- **Error Summary** فقط برای ۲+ خطا (بالای فرم)
- هدف لمسی **≥ ۴۴×۴۴ px**
- Placeholder = **مثال فرمت** (نه تکرار برچسب)
- متن خطا **blame-free**: «شماره موبایل باید ۱۱ رقم باشد» نه «ورودی نامعتبر»

## 🎨 بخش ۴ — سیستم رنگ
**قانون ۸۰-۱۵-۵:**
- ۸۰٪ خنثی (سفید/خاکستری)
- ۱۵٪ خنثی ثانویه (متن، حاشیه)
- ۵٪ رنگ تأکیدی (سبز برند)

**قواعد:**
- **یک رنگ تأکیدی** در کل اپ
- **رنگ‌های معنایی یکدست:**
  - 🟢 موفقیت (سبز)
  - 🟡 هشدار (زرد/نارنجی)
  - 🔴 خطا (قرمز)
  - 🔵 اطلاعات (آبی)
- ترکیب بیش از حد رنگ‌ها در یک صفحه → ممنوع

## 🔄 بخش ۵ — حالت آبشاری
- فیلد فرزند از والد تغذیه می‌کند
- تا انتخاب والد → فرزند **غیرفعال**
- پاک کردن والد = **پاک کردن فرزند**
- **حداکثر عمق ۲ سطح**
- محتوای فرزند در زمان اجرا ساخته می‌شود

## 📍 بخش ۶ — SourceBadge (منبع داده)
- **فقط آیکون ۱۶×۱۶** (نه بج بزرگ)
- **داخل برچسب فیلد** (نه زیر فیلد)
- **Tooltip** برای متن کامل
- حالت **دستی/خالی → بدون آیکون**
- آیکون‌ها:
  - ✓ سبز = از استاندارد
  - ⚡ آبی = از preset
  - ⬆ زرد = از والد

## ⌨️ بخش ۷ — Autocomplete
- **Inline** (نه Dropdown overlay، نه Sheet روی Sheet)
- **چسبیده به فیلد** (marginTop: -1، حس ادامه فیلد)
- **سایه + حاشیه سبز** برای تشخیص باز بودن
- **حداکثر ۵ پیشنهاد** (GOV.UK)
- **دکمه افزودن دلخواه** همیشه
- **بسته شدن فوری** (بدون انیمیشن)
- ایموجی کنار نام (🐔🐦🦆🦃🦢)
- ✓ برای آیتم انتخاب‌شده

## ♿ بخش ۸ — دسترس‌پذیری (A11y)
- **Focus Visible** فقط برای کیبورد (نه موبایل)
- روی موبایل/لمس → هیچ outline
- **aria-label** برای آیکون‌ها
- **کنتراست ≥ 4.5:1** برای متن
- **Skip navigation** برای صفحه‌های طولانی
- **Keyboard navigation:** Tab, Enter, Esc, Arrow keys
- **Screen reader** با aria-describedby برای خطاها

## 📱 بخش ۹ — رفتار موبایل
- **useKeyboardSafeFocus** — فیلد میاد وسط قبل از کیبورد
- **visualViewport API** برای هماهنگی
- **بدون focus ring** روی موبایل
- **Scroll خودکار هوشمند**
- **Scroll-behavior: smooth**
- **جلوگیری از پرش** روی iOS (overscroll-behavior)

## 🚫 بخش ۱۰ — آنتی‌پترن‌ها (ممنوع)
| ❌ ممنوع | ✅ جایگزین |
|---|---|
| ۳+ ستون در موبایل | ۱ یا ۲ ستون |
| ۲+ متن کمکی زیر فیلد | یکی |
| Sheet روی Sheet | Inline |
| Focus Ring روی موبایل | Focus Visible |
| Placeholder = برچسب | Placeholder = مثال |
| رنگ تنها نشانگر | رنگ + آیکون + متن |
| خطا بالای فیلد | خطا زیر فیلد |
| Alert برای هر خطا | Inline |
| Error Summary جایگزین Inline | هر دو (۲+ خطا) |
| فاصله‌های دلبخواه | مضرب ۸ |
| چند رنگ تأکیدی | یک رنگ |
| فایل > ۴۰۰ خط | شکستن منطقی |
| کد در جای اشتباه | mod/xxx یا shr/ |

## 🏗️ بخش ۱۱ — معماری
- **قابلیت سراسری** → shr/
- **قابلیت ماژولی** → mod/xxx/
- **هسته** → cor/
- **هر فایل ≤ ۴۰۰ خط** (استثنا: داده/تست)
- **یه تغییر در هر مرحله**
