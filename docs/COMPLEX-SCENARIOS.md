## ۱. گله مختلط (Mixed Breed)

### مسئله

کاربر ممکن است گله‌ای با چند نژاد، یا نژاد محلی داشته باشد.

### تصمیم

~~~ts
type FlockBreed =
  | { kind: 'standard'; breedId: string }
  | { kind: 'mixed'; label?: string };
~~~

### قاعده

- **استاندارد:** همه فرمول‌ها، گزارش‌ها کار می‌کنند
- **مختلط:** سیستم نمی‌شکند؛ گزارش‌ها در دسته «گروه مختلط»؛ کاربر `label` می‌گذارد
- **مرز فنی:** جایی که نژاد استاندارد لازم است (مثل فرمول خوراک)، `kind` باید `'standard'` باشد — کامپایلر خطا می‌دهد

### UI

- انتخاب نژاد: `SmartSelect` استاندارد
- ورودی ثانویه: «نژاد مناسب پیدا نکردم → ساخت گله مختلط»
- حالت مختلط: فیلد متن اختیاری

### مرجع

RemoteFarm — «Any breed (mixed)»، Farmbrite — «Set Group»، DDD — Bounded Context

### وضعیت

⏳ طراحی

## ۳. نژاد محلی با نام مستعار

### مسئله

نژاد `"Ross 308"` بعضی جاها «قزلباش» نامیده می‌شود.

### تصمیم

~~~ts
interface Breed {
  id: string;
  name: string;
  aliases?: string[];
}
~~~

جستجو و انتخاب، هم `name` هم `aliases` را چک می‌کند.

### چرا بهتر از فیلد متن آزاد

- داده استاندارد می‌ماند (قابل محاسبه)
- نام محلی پذیرفته می‌شود
- جستجو هوشمند

### مرجع

## ۴. ترکیب درمانی مدرن + گیاهی

### مسئله

کاربر می‌خواهد هم شیمیایی و هم گیاهی تجویز کند. تداخل ممکن است.

### تصمیم

~~~ts
type TreatmentLine = {
  paradigm: 'chemical' | 'herbal' | 'traditional' | 'supportive';
  refId: string;
  dose?: string;
  notes?: string;
};
~~~

یک نسخه = چند `TreatmentLine`. لایه ایمنی (`checkParadigmConflicts`) تداخل را هشدار می‌دهد.

### مرجع

نرم‌افزارهای TCM چین — دیتابیس موازی + هشدار تداخل

## ۶. دسترسی مستقیم به state ماژول دیگر

### تصمیم

- **خواندن sync:** `useB(s => s.field)` در کامپوننت
- **مقدار یک‌باره در api/handlers:** `useB.getState()` مجاز
- **mutation:** فقط از action ماژول B
- **cross-module mutation:** از `bus.emit`

### چک

`scripts/check.sh` موارد `.getState()` در `.tsx` خارج از `api/`/`handlers` را ریپورت می‌کند.

### وضعیت

## ۷. الگوی «قفل تا انتخاب والد»

### تصمیم

- فیلد B **نمایش داده نمی‌شود** (نه غیرفعال)
- وقتی A انتخاب شد، B ظاهر می‌شود
- اگر A عوض شد و B مقدار داشت → B پاک می‌شود

### مرجع
